CLASSROOM TOOLKIT — QUIZ BUILDER TEMPLATE
==========================================

HOW TO USE
1. Copy everything below the line into ChatGPT (or another AI).
2. Fill in the subject / level / topic in the prompt, or ask the AI to adapt the example.
3. Ask the AI to return ONLY the filled quiz in the same format (no extra commentary).
4. Copy the AI's quiz text.
5. In Quiz Builder, click "Import from AI", paste, and Import.

Subject: [e.g. Drama / Art & Design]
Level: [e.g. BGE S1–S3 / National 5]

Rules:
- Return ONLY the quiz in the exact format below. No markdown, no introduction, no closing notes.

- Include a Time: value in seconds (usually 20).
