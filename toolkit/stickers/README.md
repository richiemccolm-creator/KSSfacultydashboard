Sticker images for the Mini Whiteboard, from Google's Noto Emoji
(https://github.com/googlefonts/noto-emoji, tag v2026-09-24-unicode18_0, folder 2D/svg),
used under the Apache License 2.0. A width and height of 128 were added to each file so
browsers can draw them onto a canvas. File names match the sticker ids in
toolkit/whiteboard-join.html, toolkit/whiteboard.html and wb_sanitize_strokes.
