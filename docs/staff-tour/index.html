Tutorial A · Teacher Planner

Your classes live on the timetable

There isn’t a separate “class list”. You set up classes by filling periods: subject + class name + room. That grid becomes Today, Week, and where you schedule lesson plans.

Fast path

Import faculty timetable

Timetable settings → Import faculty timetable → pick your name → Import. Then tweak any period.

Manual path

Edit timetable

Open Timetable → Edit → type Class / Room in each period → Save changes.

A1 · Set up classes Demo timetable

Fill each period like a class slot

  1. 1Open Teacher Planner → Timetable tab
  2. 2Click Edit timetable
  3. 3For each teaching period: choose Subject → type Class (e.g. 1A Drama) → Room (e.g. Drama Studio)
  4. 4Optional: set period times at the top → Save changes
Do this once at the start of term

After save, the top bar should show your room (e.g. Drama Studio) and the grid lists every class you teach.

A3 · Plan lessons onto classes Demo week

Attach a plan to a period

  1. 1Open the Week tab
  2. 2Click a period that has a class (e.g. Mon P1 · 1A Drama)
  3. 3Add title, intentions, activities → save as Planned / Draft
  4. 4Repeat for the periods that need planning this week
Today view is great on teaching days. On weekends (or free days), use Week to plan ahead.

A4 · Build once, reuse Demo bank

Lesson Bank = your reusable kits

  1. 1Open Lesson Bank → + Add lesson
  2. 2Write a reusable block (warm-up, status scene, plenary…)
  3. 3Later: click Schedule on a card → pick date + period with your class
  4. 4Filter by Drama / Drafts / Planned as the bank grows
Try after this tutorial

Create one bank lesson called “BGE Warm-up · Voice & focus”, then Schedule it onto next Monday’s first Drama class.

No pupil accounts for the core tools. Favourite what you use, pin mental muscle memory for Timer → Quiz → Exit ticket.

Pace a task from the board

  3. 3Label the activity (e.g. Group rehearsal · freeze frames)

B3 · Quiz Builder mini-lesson Demo host lobby

Host a plenary quiz

  1. 1Open Quiz Builder → use a sample or New quiz
  2. 2Click Host on the quiz card
  3. 3Choose Teacher paced (you reveal) or Pupil paced
  4. 4Start together / Fullscreen — phones need sign-in for live join; board-only still works
Optional: Generate with AI on the Quiz home — answer prompts, paste the quiz back in.

Bonus · Subject trackers

Different “classes”: tracking classes

Planner classes = timetable slots. Tracker classes = pupil lists for scores. You usually set both up at the start of term.

Bonus 1 · Set up tracker classes Demo pupils

Add a class, then paste names

  1. 1Open Drama / Art / Photo Tracker
  2. 2Class Setup → year (S1/S2/S3) → type class name → + Add Class
  3. 3Add pupils one-by-one or Bulk add (paste names, one per line)
  4. 4Save — cloud sync when signed in
